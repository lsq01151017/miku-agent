# 修改记录 —— 每一轮要什么、改了什么、为什么、怎么证明

每一轮一段，按时间先后。改动本身的原始出处是 `D:\二面\cortico` 的 git 历史（提交号写在段末），
这份文件写的是历史里看不到的部分：**为什么这么改**，以及**怎么证实改对了**。
版本一（`my-agent/`）不是 git 仓库，只有一段概述。

---

## 0. 版本一：Python 单体（先做出来的那套）

- **要什么**：题目 Lv1（持续状态 / 人格 / 记忆 / 行动）到 Lv2（记忆生命周期），并带一个能看的形象。
- **是什么**：`router.py` 判断这一轮该"回答"还是该"行动"；`local_agent.py`（Ollama `deepseek-r1:14b`）
  出人格、语气、情绪与记忆注入；`api_agent.py`（DeepSeek `deepseek-flash`）出工具调用与真实行动；
  `memory.py`（SQLite）管存储 / 检索 / 覆盖修正 / 遗忘 / 衰减 / 巩固；`state.json` 存情绪；
  `live2d/avatar_server.py` 自起形象服务（端口 8765）。
- **怎么验证**：脚本化验收用例 + `logs/agent_log.jsonl` 每轮一个 `trace_id`。
- **局限（如实）**：单体、没有扩展点；加一个渠道或换一个模型都要动那几个 20–56 KB 的 `.py`；
  人格与协议细节混在同一个文件里。取舍细节见 `my-agent/README.md`。

## 1. 定底座：把 Cortico 拿下来当版本二（c8c06b4）

- **要什么**：以 Lv3（表现力）为主，但基础框架用它的，保持人家原有的扩展性与优势；能直接用的就用，
  不怕改核心；记忆方面着重学它的做法；与题目要求冲突时以题目为准；不要它自带的直播与 QQ 那几路。
- **改了什么**：把 Cortico 上游（MIT）vendor 进 `cortico/`，记下版本。
- **为什么**：题目要的是"持续状态 / 人格 / 记忆 / 行动"的智能体，Lv3 要表现力。Cortico 已经把
  Core（语义无关的内核）/ Persona / Memory / World / Bot 分开，表现力正好能做成一个 World 扩展包：
  加渠道、换模型、调人格都不动别人的代码。
- **怎么验证**：vendor 之后 `pnpm test` 与 `pnpm run typecheck` 直接绿。

## 2. 人格包：先让她"是她"（e7a6029）

- **改了什么**：`bots/miku` 继承 Cormini（工作区记忆、Git 记账、交接、心跳、工具面都来自基类），
  加角色宪法、带 EMOTION 段的前缀模板、六维情绪状态（存在 `CoreApi.personaState()`）。
- **为什么**：只有**离散心情**进系统前缀——连续六维每轮都在变，会把前缀复用切碎，而心情很少换档；
  词典是"这句话对说话人意味着什么"的启发式推断，不是系统能确认的事实，所以做成可关的开关
  （`emotion.enabled` 关掉后状态冻结，前缀照常渲染）。
- **怎么验证**：情绪衰减半衰期的断言——第一版把 `decayScale` 乘反了，是断言抓住的。

## 3. 接入本地模型：Ollama provider 与文本端点的工具协议（3befe8b / 26a7baa / a3af296 / 96844a3）

- **要什么**：本机 Ollama `deepseek-r1:14b` 也要能跑。
- **改了什么**：① `cortico-provider-ollama`（把 `reasoning` 改名成 `reasoning_content`，复用框架
  自己的 transport；窗口没实现，因为 Ollama 不报运行时窗口，拿不到的字段就是死代码）；
  ② 文本端点的工具协议 `src/tool-protocol.ts`：Chat 模板缺 `.Tools` 的模型收不到请求体的 `tools`，
  它会把调用写成正文，端点上把围栏块翻成一次调用；③ 打开 `toolProtocol.enabled` 后把工具表写进
  前缀最后一段；④ 工具表瘦身成"每个工具一句话"（前缀 6846 → 4764 字符）。
- **为什么**：模型属于端点条目，能不能收结构化声明是传输层能确认的事实，提示词只负责教学；
  工具表取自 `declareSessions()` 而不是另拼一份清单——前缀里写错工具名等于教模型调一个不存在的工具。
  工具表每轮随前缀重发，而描述本来是写给"能收到结构化声明"的模型的，所以只取第一句。
- **怎么验证**：协议在流式与非流式两条路径上的用例；断句要求句点后跟空白或行尾，否则 `[blob ...]`
  里的省略号会把句子切成半截。

## 4. 记忆的机械部分：三层、容量门、写矩阵、当场忘记（4283196 / 8ba333a / ef3a4a7）

- **要什么**：Lv2 的记忆生命周期要真的成立，不是靠提示词自觉。
- **改了什么**：`memo/` 三层（常驻层全文进前缀 / `active/` 只列名 / `archived/` 只报条数，容量 7 / 21，
  满了不自动下沉，回执报当前占用与成员名单并指向 `move_file`）；写矩阵（主意识可写可改可搬但不能删，
  `people/` 只许追加，宪法清醒时只读）；`forget` 工具当场删文件**并请求重建系统前缀**；
  人物档案的概括改成取第一条正文而不是第一行标题。
- **为什么**：常驻内容住在系统前缀里，而前缀只在会话建立、交接与清空时重建——删了文件也照样发，
  所以"明确要求忘记"必须开一个重建入口给 Persona；容量是机械规则，所以硬拦。
  真实模型写档案时先写 `# 名字` 再写正文，抽取器只看第一行就只拿到标题，所以是机械层迁就它的写法。
- **怎么验证**：端到端——第一批含秘密、最后一批不含（前缀 5346 → 5316 字符）；真实模型在两轮内写下
  `people/制作人.md`，下一轮答出了"秋天"。

## 5. 梦：交接后整理记忆（19b2666 / 30e0014）

- **改了什么**：一次交接一场梦（串行队列，并发写工作区会互相踩），从交接前的快照 fork，
  结束时的 `surface` 回到醒来那一侧；修 `nudge` 的条件（整轮都在调工具、一个字没写也要拿到收尾机会），
  并把"该收尾了"的引导写进提示词。
- **为什么**：本地窗口只有 4096 token，引导要紧凑版，留给动态尾的余量按预算比例算（写死 8000 会在
  3072 的预算上把动态尾挤成零）；梦排在 `super.onHandoff` 之后，交接笔记要先落盘它才读得到。
- **怎么验证**：实测 12 场梦里浮现 6 → 7，撞硬上限归零。

## 6. 表现力地基：把素材包读成通道值（21c13a1）

- **改了什么**：三层合成——情绪算出的**基线**一直在，词表命中的**片段**叠上去，最后按量程裁剪；
  片段三种形状都支持（关键帧 `pulse`、保持值 `sustain`、视线 `gaze`）；噪声与扫视是时间的纯函数
  （正弦，不是随机数）；长词优先、别名归一；包里提到的片段缺失时列进 `missingClipIds` 而不是静默跳过。
- **为什么**：题目硬要求"身体由内部状态驱动"，基线就是那一层；静默跳过会让"特效为什么不出现"变成谜。

## 7. 形象 World：自己起渲染服务，把通道推给页面（75d92f8 / 840800b / 31c6f5c / a77d84a / a0cc00b / 81f71ea）

- **改了什么**：`live2d` World 自起 HTTP 服务（只绑 127.0.0.1，`/state` 用 SSE 推通道值，只在内容变了
  或正在说话时播发）；`outputTap` 收正文增量走词表触发片段；`externalizes` 只在**真有页面看着**
  且这一轮确实说了字时为真；通道按模型自己的参数表核对；表情由离散心情驱动；随包资源（`web/`、
  `ENV_PROMPT.md`）列进 `package.json` 的 `files`；页面测试用替身浏览器跑页面自己的逻辑。
- **为什么**：不碰控制台前端——改它要重建 Web 产物，而重建必须在没有 bot 活着的时候做。
  通道的 `suggests` 只是建议：这份模型上有 `Paramguzui` 这种拼音命名，包里建议的 `ParamCheekPuff`
  根本不存在，那一路表演此前是静默失效的，所以拿模型的 `DisplayInfo`（cdi3）核对并把对不上的通道
  连同"丢了什么"一起报出来。配置问题在挂载时就报，不留到有人打开页面才发现。
- **怎么验证**：真实包 + 真实模型的参数表，唯一对不上的就是腮那一条，这条进了测试。

## 8. 睁开眼、关掉水印（2adf62a / 1264ea1 / ec3999a）

- **要什么**：水印没关掉。
- **根因**：不是配置错，是**写的时机**——Cubism 每帧把参数复位成模型默认值，复位发生在 pixi 自己的
  更新里；在自己的 rAF 里写和它的顺序不定，写早了当帧就被抹掉。另外部署里钉的是 `Param137=0`，
  而那正是模型默认值、也就是"水印开着"的一档。
- **改了什么**：参数覆盖改到模型的 `beforeModelUpdate`（复位之后、更新之前）；部署钉 `Param137=1`。
- **怎么验证**：用真的 Cubism core 驱动模型文件实测——`Param137=1` 时三层水印（ArtMesh58 / 59 / 28）
  的不透明度从 1 变 0。模型文件没有改动；测试只覆盖管线（真模型不是仓库夹具）。

## 9. 她说的话从哪来：工具参数里的台词，措辞就是演出指令（962d772 / 189ff5a）

- **要什么**：脸上一直没有表情变化。
- **根因**：① 她的台词是**带 `speak` 标签的工具的参数**说出来的，正文一个字符都不在
  `response.output_text.delta` 里，挂在输出上的 World 只能收到参数增量，所以形象层一直以为她没说话；
  ② 表情层只认离散心情，而心情不常换档。
- **改了什么**：覆写输出旁路，按说话工具的 `parameters` 找到装话的那个字符串字段，把参数流翻成正文流
  再交给各 World（字段名从工具声明里读，不写死 `text`）；素材包新增 `expressions.json`
  （`{ expression, words[] }`），正文命中就挂模型自带的那个表情，压过心情那张，`expressionHoldMs`
  到期回到心情；帧里多一个 `expressionToken`（名字没变也要能重放同一张表情）；说话时长改为按字数估。
- **为什么**：参数是流式拼出来的，`partialStringArgument` 在结尾的 `\` 与 `\uXXXX` 到齐前不吐字；
  她的话算外部输出，这一轮不该被新输入抢占。
- **怎么验证**：真实一轮里命中表情与片段；同一段正文按不同位置切分得到同一串文本。

## 10. 删掉四个不用的渠道（94bcb5c / 04a0573 / 29d3f81）

- **要什么**：不要它的直播和 QQ 那几路，专注 AI 人格。
- **改了什么**：删 QQ / B站直播 / Minecraft / 联网搜索四个 World 与只服务它们的代码、依赖

- **为什么**：渠道是扩展点，不是内核功能；留着一万九千行不用的源码与依赖只是负担。
- **怎么验证**：契约测试收敛到剩下的 World，`pnpm typecheck` 与测试绿。

## 11. 她自己会动起来、形象页有数可取景（fde0010）

- **要什么**：不管说什么都像只有一个动作；画面上看不出任何数值；不能调她的位置。
- **改了什么**：**待机层**——呼吸、微晃、视线游移，几个不同周期的正弦，一直在（`idleAmount` 可关）；
  **说话自带动作**——每句起音一次 `speech_onset`，之后每说满 14 个字点一下头；推流帧带上面板要的
  `emotion` / `mood` / `clips`；右侧数值面板 + 取景（缩放 / 左右 / 上下 / 直接拖动 / 复位 / 记住）。
- **为什么**：以前只有情绪基线与词表片段，她不说不动的时候就是一张静止的图；取景只影响画面，
  不回写模型。
- **怎么验证**：待机随时间变且同刻同值、`idleAmount=0` 完全静止、起音与重音轮换不重复、
  页面上的条宽与数字来自帧、缩放/偏移/拖动/复位/记住都对。

## 12. 改完扩展源码要重装一次快照（4a9b5b2）

- **为什么**：启动器读的是 `extensions/node_modules/<包名>`，不是 `extensions/<包名>` 源码目录；
  `file:` 依赖会被缓存，不重装就跑上一次那份——形象页改了却没生效就是这个。
- **做法**：写进 `docs/development.md`；每次改完扩展源码跑一次 `pnpm install` 刷新快照。

## 13. 眼神自己算，腰不许跟着鼠标转（3cafd76）

- **要什么**：眼睛跟得慢；而且一拖鼠标她的腰跟着转。
- **根因**：播放器库自带的指针交互把指针位置映射成单位圆上的角度，速度上限约 0.6/s（整程约 1.6 秒才
  走完），并且写 `ParamBodyAngleX = 10x`。
- **改了什么**：关掉自带交互（`autoInteract: false`），自己按指针位置算眼神（时间常数 0.03s），
  一个身体参数都不写。
- **怎么验证**：推到最右 8 帧（≈134ms）眼睛偏移走过 0.6 以上且是叠加写；`ParamBodyAngle*` 一个都不出现；
  指针离开后回到 0.1 以内。

## 14. 对话框搬进形象页，页面与脚本不吃缓存（d681956 / 7b68be9）

- **改了什么**：形象页底部加输入区（走 `/chat` WebSocket，或用 `/agent/chat` 走外部 Agent）；
  页面与脚本的响应带 `no-store`。
- **为什么**：刷新后新旧脚本混在一起，谁也看不出改动有没有生效。

## 15. 她的话走字幕，输入区与按键换成磨砂玻璃（2cc86f8）

- **要什么**：她的回答做成浮在模型上方的字幕；底部只留我发出去的话；面板与按键统一磨砂玻璃。

## 16. 让她张嘴（a3ef03a）

- **要什么**：让她张嘴时没有对应动作。
- **根因**：词表里没有这组词，而这种片段要词汇命中才会触发；而且说话时口型通道被振荡器占着。
- **改了什么**：素材包加 `mouth_open` 片段（口型 0 → 0.95 → 0.9 → 0.35 → 0.85 → 0，约 1.6 秒）与
  「张嘴 / 张开嘴 / 张大嘴 / 张开嘴巴 / 啊——」等词；口型取"振荡器与通道值的较大者"，
  不然片段里的口型会被说话的振荡遮住；操作员在控制台打的话也递给表现层（以前只喂情绪那一路）。
- **怎么验证**：实测操作员发「张嘴」→ 活着的片段里有 `mouth_open`，`MouthOpen` 峰值 0.95，
  且峰值落在**不说话**的那些帧上。

## 17. 字幕更扁、输入区收起历史、口型听 World（2a56f59）

- **改了什么**：字幕不收边更扁；输入区只留最近一句、其余收起可展开；口型改由 World 的说话时长驱动。

## 18. 面板收起更多、取景不把她弄丢（88d7faa）

- **改了什么**：内部状态面板里数值之下的东西默认收起（「更多」展开，选择记在本地）；取景加边界，
  至少留 80px 的她还在画面里。
- **注意**：这一轮把"贴合窗口的比例"的计算挪进了 `applyTransform`，埋下了第 22 轮的 bug。

## 19. 字幕衬底回一版、比输入区略长（168b02e）

- **要什么**：拖动时出现两个模型；字幕衬底回去一版，宽度比对话框略长。
- **改了什么**：画布加 `draggable="false"`、`-webkit-user-drag` / `user-select` / `touch-action`，
  `pointerdown` 与 `dragstart` 都 `preventDefault`，`boot()` 加只进一次的守卫。
- **结果**：影子还在——真正的原因不在拖拽，见第 22 轮。

## 20. 换成一个透明覆层接指针（dd501ca）

- **改了什么**：画布上盖一层 `#hit`，指针事件全落在它身上，拖动取景的逻辑搬到覆层；文档级
  `dragstart` 拦截兜底；字幕行高 1.32 → 1.12；字幕与输入区放进同一个底部竖栏（输入区展开时字幕
  跟着上升，两者不再叠在一起）。
- **结果**：影子还在。这一步排除了"画布被浏览器拖走"这条路。

## 21. 字幕行高收到 1（c6e1d5b）

- **改了什么**：行高 1、上下内边距归零（字号不变）；流式吐字时行尾空白与连续空行不再占位。
- **为什么**：`white-space: pre-wrap` 会把行尾空格和空行原样排出来，看着就是凭空多出的行距。

## 22. 根因：贴合比例把缩放乘重了（2127633）

- **她看到的**：一拖动就有一层比原模型大得多的影子跟着鼠标，松手立刻消失。
- **根因**：模型在 PIXI 里是容器，`width` / `height` **含当前缩放**。第 18 轮把比例计算挪进
  `applyTransform` 之后，拖动每动一下就算一次，比例变成 `R / 当前缩放`，于是缩放按 `1 ↔ R` 反复
  取反：她在"贴合窗口"和"自然尺寸"之间来回跳。屏幕上就是一张大得多的她跟着鼠标，交替出现看着像
  两个模型——所以所有挡拖拽的办法都没用，它压根不是 DOM 拖拽。
- **改了什么**：加载完成、`scale` 还是 1 的那一刻量一次模型自己的尺寸，贴合比例与取景边界一律用它。
- **怎么验证**：页面测试的模型替身改成 `width` / `height` 随缩放变（这是它此前漏掉这个 bug 的原因），
  新增断言"连续拖动两次缩放不变"；把旧算法放回去跑，这条断言立刻失败（期望 9、实为 1）；
  换回新算法，扩展与页面的 85 项测试全过、`tsc --noEmit` 干净。
